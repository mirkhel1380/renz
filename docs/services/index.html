How to compare a quote

  • Ask for the state filing fee, provider charge, and optional items on separate lines.
  • Confirm which services renew and whether renewal is automatic.
  • Ask what happens if the filing needs a correction or the provider cannot accept your application.

Choose by where you are now

  • Still deciding: compare formation states and identify where you actually plan to operate.
  • Ready to form: gather the information the state asks for and request an itemized formation quote.
  • Already formed: check whether you need to appoint or change an agent, apply for an EIN, or prepare for a renewal.

Compare the first two years

Write the provider setup charge and government filing fee in a first-year column. Put agent renewal, optional address service and applicable state filings or taxes in a second-year column. Ask for the billing schedule before choosing.

Keep your records together

Retain your quote, accepted filing, agent agreement, EIN confirmation if applicable, and a list of recurring dates. Use the setup resources to build your own checklist.
