    Decide based on how you operate

    • Consider where you have an office, employees, or regular business activity.
    • Compare the cost to form, annual filings or taxes, and renewal charges for a registered agent.
    • Ask whether you may also need to register in another state where you operate. The SBA registration guide covers this question.

    Compare the full cost of a state

    Start with the formation fee and annual state requirements. Add the cost of a registered agent, optional address services and any registration needed in a second state. Use each filing office’s current fee schedule.

    Example: operating in another state

    If you are considering one state for formation and another for your day-to-day business, look up both states' requirements before choosing. The SBA registration guide explains how foreign qualification may apply.

    What the directory does

    The three featured guides link to state-specific filing instructions. Selecting another state from the directory opens a general checklist with that state preselected.
