What to include in a question

  • The state you are considering, or where the company is already registered.
  • The service you need and whether you have already filed any documents.
  • The provider name and package you are comparing, if applicable.
  • One or two specific points you want clarified. Leave out sensitive numbers and documents.

Find the right source

For filing status or a state form, start with the official office linked in the state guides. For EIN application questions, see official IRS guidance. For package billing or a refund, contact the provider that issued the invoice.
